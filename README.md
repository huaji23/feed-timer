# 喂奶计时

半夜 3 点单手操作设计的喂奶记录工具。**PWA**（网页加到手机主屏幕，跟 App 一样），离线可用，数据只存本机。

## 线上地址

**https://huaji23.github.io/feed-timer/**

手机浏览器打开 → 分享 → **添加到主屏幕** → 主屏出现 🍼 图标，点开全屏运行。
**首次打开需要联网，之后断网也能用。**

实测国内访问：首字节 0.25~0.7s。

## 怎么用（手机上）

1. 手机浏览器打开上面的网址
2. Safari → 分享 → **添加到主屏幕**
3. 主屏幕会出现 🍼 图标，点开全屏运行，没网也能用

> ⚠️ **iOS 限制**：App 完全关掉后不会发通知（系统限制）。要可靠提醒，请在
> iPhone「设置 → 通知 → 找到本网页 → 允许通知」，并在喂奶时保持 App 开着或用完随手后台。

## 功能

### 计时
- **一键开始 / 结束**：点大圆开始，再点结束，自动算时长
- **暂停 / 继续**：喂一半拍嗝、换尿布时暂停，不算进时长
- **左右侧分别计时**：母乳模式下左右各一块，喂哪边点哪边；开始前可预选起始侧
- **换边提醒**：一侧喂够设定时长（默认 12 分钟）另一侧会闪烁提示

### 三种模式
| 模式 | 记录内容 |
|---|---|
| 母乳 | 时长 + 左右侧各自时长 |
| 瓶喂 | 时长 + 奶量（ml） |
| 吸奶 | 时长 + 奶量（ml） |

### 统计
- 今日：次数 / 总时长 / 平均间隔 / 距上次多久
- 近 7 天：喂奶时长柱状图、次数柱状图
- 尿布（尿 / 大便）次数、当日总奶量、最新体重

### 提醒
- 超过设定间隔没喂 → 系统通知（默认 3 小时）
- 夜间免打扰时段（默认 22:00–06:00）内不打扰，超时 1.5 倍才提醒
- 换边提醒

### 数据
- **全部存本机**（localStorage），不上传任何服务器
- 导出 CSV（Excel 直接打开，给医生看）
- 备份 / 恢复 JSON（换手机不丢数据）

## 技术要点

**时长按时间戳实时算，不靠定时器累加。**
iOS 在 App 切到后台时会冻结 JS 定时器，如果用 `setInterval` 累加时长，
冻结的那段时间就丢了。现在的做法是：

- `acc` = 已结算毫秒，`start` = 上次结算时刻
- 显示值 = `(acc + (now - start))` 实时算
- 定时器恢复后 `accrue()` 一次即可把整段时间补回

所以**切到微信聊天半小时再回来，时长照样准**。

## 本地预览

```bash
cd ~/Downloads/personal/feed-timer
python3 -m http.server 8977
# 打开 http://127.0.0.1:8977/
```

手机上要用，需要让手机和电脑在同一 WiFi，然后访问 `http://<电脑IP>:8977/`，
再「添加到主屏幕」。
